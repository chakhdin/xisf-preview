# XISF & FITS FastViewer и Расширения Проводника Windows

Высокопроизводительное расширение оболочки Windows Shell и быстрый автономный просмотрщик астрономических изображений в форматах **XISF** (PixInsight Extensible Image Serialization Format) и **FITS** (`.fits`, `.fit`, `.fts`).

---

## Основные возможности

- **Эскизы в Проводнике Windows**: Нативное расширение `IThumbnailProvider` для быстрого построения качественных миниатюр прямо в окне папки.
- **Панель предварительного просмотра**: Интеграция с `IPreviewHandler` для полноразмерного просмотра несжатых кадров на панели предпросмотра Проводника (`Alt + P`).
- **Связанный AutoSTF по алгоритму PixInsight**: Точная реализация связанной функции растяжения гистограммы Screen Transfer Function (ур. 8.5.7) на основе объединенной медианы и MAD-статистики каналов, устраняющая паразитный цветовой оттенок на сырых линейных кадрах.
- **Оптимизированный ввод-вывод**: Чтение данных блоками напрямую в память и многопоточная обработка для моментального открытия тяжелых многомегапиксельных сырых кадров с ПЗС- и КМОП-сенсоров.
- **Просмотрщик FastViewer**:
  - Автоматическое масштабирование по размеру окна при запуске.
  - Асинхронная фоновая предзагрузка соседних кадров для мгновенного перехода (**Следующий** / **Предыдущий**).
  - Интерактивная HUD-панель гистограммы с поддержкой оперативной настройки параметров растяжения в реальном времени.
  - Безопасная установка по умолчанию: регистрирует системные генераторы эскизов и предпросмотра, сохраняя существующие ассоциации файлов (PixInsight, ASIFitsView и др.).

---

## Поддерживаемые форматы

| Формат | Расширения | Разрядность / Типы данных |
|---|---|---|
| **XISF** | `.xisf` | 8-бит UInt, 16-бит UInt, 32-бит Float (Planar и Interleaved, без сжатия) |
| **FITS** | `.fits`, `.fit`, `.fts` | 8-бит UInt, 16-бит Int/UInt (с калибровкой BZERO/BSCALE), 32-бит Int, -32 IEEE Float |

## Установка

1. Скачайте установочный файл `XisfFastViewerSetup.exe` на вкладке [Releases](https://github.com/chakhdin/xisf-preview/releases).
2. Запустите `XisfFastViewerSetup.exe` от имени администратора.
3. Перезапустите Проводник Windows или перезайдите в учетную запись, если эскизы не обновились сразу.

> **Примечание**: По умолчанию установщик регистрирует только службы предпросмотра Shell и добавляет FastViewer в контекстное меню Windows «Открыть с помощью...». Текущие ассоциации файлов для открытия двойным кликом остаются без изменений, если при установке не был вручную отмечен соответствующий пункт.

## Горячие клавиши (FastViewer)

| Клавиша | Действие |
|---|---|
| `PageDown` / `Стрелка вправо` | Следующий кадр в текущей папке |
| `PageUp` / `Стрелка влево` | Предыдущий кадр в текущей папке |
| `Пробел` | Пересчитать и применить связанный AutoSTF |
| `F` | Вписать изображение в границы окна |
| `H` | Показать / скрыть HUD-панель гистограммы |
| `Колесо мыши` | Плавное масштабирование с центром под курсором |
| `ЛКМ + Перетаскивание` | Панорамирование (перемещение) по изображению |
| `Esc` | Закрыть программу |

## Сборка из исходного кода

### Требования
- [.NET Framework 4.8 Developer Pack / SDK](https://dotnet.microsoft.com/download/dotnet-framework/net48)
- [Inno Setup 6](https://jrsoftware.org/isdl.php)

### Сборка

```powershell
# 1. Сборка бинарных файлов в конфигурации Release
dotnet build -c Release

# 2. Компиляция установочного пакета
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

Собранный дистрибутив будет сохранен по пути `bin\Installer\XisfFastViewerSetup.exe`.
